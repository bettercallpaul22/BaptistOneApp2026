# Fix: "BaptistOneApp" has not been registered (iOS)

## Root Cause

Name mismatch between JavaScript and iOS native code:

| File | Module Name |
|------|-------------|
| `app.json` (line 2) | `"Baptist One"` (with space) |
| `AppDelegate.swift` (line 27) | `"BaptistOneApp"` (no space) |

`index.js` registers the component using the name from `app.json` → `"Baptist One"`. iOS native code looks for `"BaptistOneApp"`. They don't match → app is "not registered".

## Fix

**Change `app.json`** to use `"BaptistOneApp"` (no space) for the internal module name:

```json
{
  "name": "BaptistOneApp",
  "displayName": "Baptist One"
}
```

The `"displayName"` keeps the user-visible name with a space. The `"name"` field is the internal React Native module identifier and should not contain spaces (avoids issues with native modules and build tooling).

**File:** `app.json:2`

## Verification

1. Kill Metro if running (`Ctrl+C` in the Metro terminal)
2. Run `npx react-native run-ios` from the project root
3. App should launch without the "not registered" error
