# Android Back Button Double-Press-to-Exit

## Summary
Add an Android hardware back button handler in `App.tsx` that shows a ToastAndroid message on first press and exits the app on second press within 2 seconds.

## File to Modify
- `/Users/progressive/Documents/projects/new_baptist/BaptistOneApp/App.tsx`

## Implementation

Add a `useEffect` hook that:
1. Registers a `BackHandler` listener for `hardwareBackPress`
2. On first press: shows `ToastAndroid.show('Press back again to exit', ToastAndroid.SHORT)` and returns `true` (prevents default exit)
3. On second press within 2 seconds: returns `false` (allows default exit behavior)
4. Cleans up the listener on unmount

```tsx
import { BackHandler, ToastAndroid, ... } from 'react-native';

// Inside App component:
useEffect(() => {
  const backHandler = BackHandler.addEventListener('hardwareBackPress', () => {
    // show toast and prevent exit
    // on second press within 2s, allow exit
  });
  return () => backHandler.remove();
}, []);
```

## Verification
1. Run `npx react-native run-android`
2. Press the Android back button once → toast appears, app stays open
3. Press back again within 2 seconds → app exits
4. Press back, wait >2 seconds, press again → toast appears again (timer reset)
